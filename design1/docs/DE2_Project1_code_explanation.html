1. 한눈에 보기

스위치 SW0 하나로 카운터와 한 자리 계산기를 오가는 회로입니다. 결과는 7세그먼트(HEX)에 십진수로 표시하고, 보너스로 LED 표시, 777 잭팟, 나눗셈 나머지, 16진수 표시를 넣었습니다.

코드는 크게 세 덩어리로 나뉩니다. 앞의 두 덩어리가 값을 만들고, 세 번째가 화면에 무엇을 띄울지 정합니다.

① 카운터버튼을 누른 순간을 감지해 cnt를 올리고 내립니다.
(클럭에 맞춰 동작하는 순차회로)
+
② 계산기스위치로 받은 A, B를 계산해 result, quot, remain, neg를 만듭니다.
(스위치가 바뀌면 바로 계산되는 조합회로)
→
③ 표시어느 값을 어느 HEX 칸에 띄울지 d0~d7에 정하고, seg7이 7세그 패턴으로 바꿉니다.

전체 흐름: 스위치·버튼 → (카운터 / 계산기) → 숫자 값 → 자릿수 분리 → 문자 코드(d0~d7) → seg7 → HEX0~7

4. 선언부 (architecture 앞부분)

25architecture behavior of DE2_Project1 is

27    constant BLANK : integer := 16;
28    constant MINUS : integer := 17;
29    constant CH_R  : integer := 18;

32    signal k1, k2 : std_logic_vector(3 downto 0) := "1111";  -- buttons now / one clock ago
33    signal cnt    : integer range 0 to 9999 := 0;            -- counter value
34    signal s1, s2 : integer range 0 to 10;                   -- step size
35    signal a, b   : integer range 0 to 15;                   -- calculator inputs
36    signal result : integer range 0 to 255;                  -- result of + - * (absolute value)
37    signal quot   : integer range 0 to 15;                   -- quotient
38    signal remain : integer range 0 to 15;                   -- remainder
39    signal neg    : std_logic;                               -- 1 = negative result
40    signal err    : std_logic;                               -- 1 = divide by zero
41    signal valid  : std_logic;                               -- 0 = decimal mode and A or B is 10 or more
42    signal d0, d1, d2, d3, d4, d5, d6, d7 : integer range 0 to 18;  -- what each HEX shows
  • constant : 문자 코드를 이름으로 적어 둔 것입니다. 표시할 칸마다 "무엇을 띄울지"를 숫자로 정합니다. 0~15는 16진수 숫자 0~F 그대로, 16은 빈칸, 17은 -, 18은 r입니다. Err의 E는 16진수 E(14)와 모양이 같아서 14를 씁니다.
  • signal : 회로 안의 전선·저장소입니다.
    • k1, k2 : 버튼 값을 한 클럭, 두 클럭 늦게 저장합니다. 초기값 "1111"인 이유는 버튼이 안 눌린 상태가 1이기 때문입니다.
    • cnt : 카운터 값. integer range 0 to 9999로 범위를 정하면 합성할 때 필요한 비트 수(14비트)로 알아서 만들어집니다.
    • s1, s2 : 버튼을 한 번 눌렀을 때 바뀌는 크기(모드에 따라 1/2 또는 5/10).
    • a, b : 계산기 입력(0~15). result : 더하기·빼기·곱하기의 결과(항상 0 이상, 부호는 neg로 따로 표시).
    • quot, remain : 나눗셈의 몫과 나머지. err : 0으로 나누면 1. valid : 십진수 모드에서 A나 B가 10 이상이면 0.
    • d0~d7 : HEX 8칸에 각각 무엇을 띄울지(문자 코드).

5. seg7 함수 : 코드 → 7세그 패턴

44    -- character code -> 7-segment pattern (a segment lights up when 0)
45    function seg7(c : integer) return std_logic_vector is
46    begin
47        case c is
48            when 0  => return "1000000";
49            when 1  => return "1111001";
50            when 2  => return "0100100";
51            when 3  => return "0110000";
52            when 4  => return "0011001";
53            when 5  => return "0010010";
54            when 6  => return "0000010";
55            when 7  => return "1111000";
56            when 8  => return "0000000";
57            when 9  => return "0010000";
58            when 10 => return "0001000";   -- A
59            when 11 => return "0000011";   -- b
60            when 12 => return "1000110";   -- C
61            when 13 => return "0100001";   -- d
62            when 14 => return "0000110";   -- E
63            when 15 => return "0001110";   -- F
64            when 17 => return "0111111";   -- -
65            when 18 => return "0101111";   -- r
66            when others => return "1111111";   -- blank
67        end case;
68    end function;

7세그먼트의 일곱 획에 이름(a~g)이 있고, 이 함수는 문자 코드를 받아 어느 획을 켤지(7비트) 돌려줍니다.

   a
 f   b        패턴 순서 : g f e d c b a  (왼쪽부터)
   g          DE2 보드는 0이면 켜지고 1이면 꺼집니다 (active-low)
 e   c
   d          예) 숫자 0 = "1000000" : g만 끄고 나머지 여섯 획을 켬
  • case c is when 0 => return "1000000"; 처럼 코드 값마다 패턴을 하나씩 돌려줍니다. 나머지 값은 when others에서 전부 끈 상태("1111111", 빈칸)입니다.
  • 숫자 10~15는 A, b, C, d, E, F 모양입니다. 7세그로는 B와 D를 대문자로 그릴 수 없어서 소문자 b, d로 씁니다.
  • -(17)은 가운데 획 g만 켠 모양, r(18)은 e와 g만 켠 모양입니다.

6. 카운터

6-1. 증감 크기 정하기

71    s1 <= 1 when SW(1) = '0' else 5;     -- step of button1 (+) and button3 (-)
72    s2 <= 2 when SW(1) = '0' else 10;    -- step of button2 (+)

SW1이 0이면 버튼1·3은 1씩, 버튼2는 2씩 바뀌고, SW1이 1이면 5씩, 10씩 바뀝니다. when ... else는 조건에 따라 값을 고르는 신호 대입입니다.

6-2. 버튼을 누른 순간만 감지하기 (엣지 검출)

74    process (CLOCK_50)
75    begin
76        if rising_edge(CLOCK_50) then
77            k1 <= KEY;
78            k2 <= k1;
79            if SW(0) = '0' then          -- counter mode only
80                if k2(0) = '1' and k1(0) = '0' then          -- KEY0 : reset
81                    cnt <= 0;
82                elsif k2(3) = '1' and k1(3) = '0' then       -- KEY3 : up by s1
83                    if cnt + s1 > 9999 then cnt <= 9999; else cnt <= cnt + s1; end if;
84                elsif k2(2) = '1' and k1(2) = '0' then       -- KEY2 : up by s2
85                    if cnt + s2 > 9999 then cnt <= 9999; else cnt <= cnt + s2; end if;
86                elsif k2(1) = '1' and k1(1) = '0' then       -- KEY1 : down by s1
87                    if cnt < s1 then cnt <= 0; else cnt <= cnt - s1; end if;
88                end if;
89            end if;
90        end if;
91    end process;

왜 필요한가? 버튼을 한 번 누르는 0.1초 동안 50MHz 클럭은 500만 번 돕니다. "눌려 있으면 더한다"고 하면 한 번 눌러도 500만 번 더해집니다. 그래서 "전 클럭엔 안 눌림(1), 지금은 눌림(0)"인 단 한 번만 동작하게 합니다.

클럭 번호123456
KEY3 (눌림 = 0)110000
k1 (한 클럭 전 값)111000
k2 (두 클럭 전 값)111100
k2 = 1 and k1 = 0XXXOXX

버튼을 계속 눌러도 조건이 만족되는 클럭은 딱 한 번(4번)뿐입니다. 코드로는 k2(3) = '1' and k1(3) = '0'입니다.

  • process (CLOCK_50) + rising_edge(CLOCK_50) : 클럭이 올라가는 순간마다 한 번 실행합니다. 값을 기억하는 회로(플립플롭)가 만들어집니다.
  • k1 <= KEY; k2 <= k1; : 버튼 값을 한 단계씩 밀어 저장합니다. 버튼은 클럭과 상관없이 바뀌는 신호라서 한 번 레지스터에 담아 안정화하는 효과도 있습니다.
  • 우선순위 : if / elsif 순서대로 KEY0(리셋) → KEY3 → KEY2 → KEY1입니다. 두 버튼이 정확히 같은 클럭에 눌리면 앞의 것 하나만 동작합니다.
  • 상한·하한 : 올릴 때 cnt + s1 > 9999이면 9999로 고정하고, 내릴 때 cnt < s1이면 0으로 고정합니다.
  • if SW(0) = '0' : 계산기 모드에서는 카운터가 버튼을 무시합니다. 이때도 k1, k2는 계속 갱신되기 때문에 모드를 바꿀 때 가짜 입력이 생기지 않습니다.
  • 이 프로세스는 74~91번 줄입니다.

7. LED와 777 잭팟

93    -- LEDs (counter mode only) : red = value in binary, green = jackpot at 777
94    LEDR(13 downto 0)  <= std_logic_vector(to_unsigned(cnt, 14)) when SW(0) = '0' else (others => '0');
95    LEDR(17 downto 14) <= "0000";
96    LEDG <= (others => '1') when SW(0) = '0' and cnt = 777 else (others => '0');
  • to_unsigned(cnt, 14) : 정수 cnt를 14비트 이진수로 바꿉니다. 9999까지 표현하려면 14비트(214 = 16384)가 필요해서 LEDR(13 downto 0)에 연결하고, 남은 LEDR(17 downto 14)는 항상 0입니다.
  • (others => '0') : 모든 비트를 0으로 채운다는 뜻입니다. 계산기 모드(SW0 = 1)에서는 LED를 끕니다.
  • LEDG : 카운터 모드에서 cnt = 777이면 초록 LED 8개를 모두 켭니다. HEX7~4에 7777을 띄우는 부분은 9장 표시 프로세스에 있습니다.
  • 이 부분은 클럭 없이 값이 바뀌는 즉시 반응하는 조합회로입니다.

8. 계산기

8-1. 입력 받기

99    a <= to_integer(unsigned(SW(17 downto 14)));
100    b <= to_integer(unsigned(SW(13 downto 10)));
101    err <= '1' when SW(2 downto 1) = "11" and b = 0 else '0';
102    valid <= '1' when SW(3) = '1' or (a < 10 and b < 10) else '0';
  • SW(17 downto 14)는 4비트 이진수입니다. unsigned(...)로 "부호 없는 숫자"로 보고 to_integer(...)로 정수로 바꿉니다.
  • err : 나눗셈("11")이면서 B가 0이면 1입니다.
  • valid : 16진수 모드(SW3 = 1)이거나 A, B가 모두 10 미만이면 1입니다. 한 자리 계산기이므로 십진수 모드에서 10 이상이 들어오면 결과를 띄우지 않기 위한 신호입니다.

8-2. 연산하기

104    process (SW, a, b)
105        variable q : integer range 0 to 15;
106    begin
107        result <= 0;
108        quot <= 0;
109        remain <= 0;
110        neg <= '0';
111        case SW(2 downto 1) is
112            when "00" => result <= a + b;
113            when "01" =>
114                if a >= b then
115                    result <= a - b;
116                else
117                    result <= b - a;     -- a is smaller : calculate b - a and mark negative
118                    neg <= '1';
119                end if;
120            when "10" => result <= a * b;
121            when others =>
122                if b /= 0 then
123                    q := to_integer(to_unsigned(a, 4) / to_unsigned(b, 4));
124                    quot <= q;
125                    remain <= a - q * b;     -- remainder = a - quotient * b
126                end if;
127        end case;
128    end process;
  • process (SW, a, b) : 괄호 안의 신호가 바뀔 때마다 다시 실행됩니다. 클럭이 없으니 스위치를 바꾸면 곧바로 결과가 바뀝니다.
  • 맨 위에서 기본값을 먼저 넣는 이유 : 어떤 경우에도 모든 신호에 값이 정해지게 하기 위해서입니다. 안 그러면 값을 기억하는 회로(래치)가 불필요하게 만들어질 수 있습니다.
  • 뺄셈 : a >= b이면 a - b. 아니면 b - a를 구하고 neg를 1로 합니다. 음수를 2의 보수로 다루지 않고 "크기 + 부호 표시"로 나눈 방식입니다. (3 - 7 → 결과 4, neg = 1 → 화면에 -004)
  • 곱셈 : a * b. 십진수 최대 9 × 9 = 81, 16진수 최대 15 × 15 = 225입니다.
  • 나눗셈 : b가 0이면 계산하지 않습니다. 아니면 4비트 부호 없는 수끼리 /로 나눈 몫을 q에 담고, 나머지 = a - 몫 × b로 구합니다. 예) 7 ÷ 3 → q = 2, 나머지 = 7 - 2×3 = 1
  • variable q : 신호(<=)는 프로세스가 끝난 뒤 값이 바뀌지만, 변수(:=)는 대입 즉시 바뀝니다. 몫을 계산하자마자 같은 프로세스 안에서 바로 쓰기 위해 변수를 썼습니다.
  • 이 프로세스는 104~128번 줄입니다.

162                end if;
163            end if;
  • A는 HEX6(d6), B는 HEX4(d4)에 한 자리만 띄웁니다. 십진수 모드에서 10 이상이면 그 칸은 빈칸으로 둡니다.
  • valid = '1'일 때만 결과를 띄웁니다. 즉 십진수 모드에서 A나 B가 10 이상이면 결과 칸도 비웁니다.
  • 0으로 나눔 → E, r, r을 HEX2~0에 띄워 Err가 됩니다.
  • 나눗셈 → HEX3 = 몫, HEX2 = 빈칸, HEX1 = r, HEX0 = 나머지. 예) 7 ÷ 3 → 2 r1
  • 그 외 연산 : 음수면 HEX3에 -. 16진수 모드면 두 자리(result / 16, result mod 16), 십진수 모드면 세 자리(백, 십, 일)로 나눕니다.
    예) 15 × 15 = 225 → 16진수 모드: 225 ÷ 16 = 14(E), 225 mod 16 = 1 → E1
  • 이 프로세스는 131~165번 줄입니다.

10. 출력 연결

167    HEX0 <= seg7(d0);  HEX1 <= seg7(d1);  HEX2 <= seg7(d2);  HEX3 <= seg7(d3);

12. 발표 예상 질문과 답

Q1. 버튼을 길게 눌러도 한 번만 올라가는 이유는?

누른 순간만 감지하기 때문입니다. 한 클럭 전 버튼 값(k2)이 1이고 지금 값(k1)이 0인 클럭에서만 증감합니다. 버튼을 계속 눌러도 이 조건은 처음 한 번만 참입니다.

Q2. 왜 k1, k2 두 개를 쓰나요?

하나는 현재 값, 하나는 한 클럭 전 값을 저장해서 "1에서 0으로 바뀌었는지"를 비교하려고 쓰고, 버튼이 클럭과 상관없이 바뀌는 신호이므로 레지스터에 한 번 담아 안정화하는 역할도 합니다.

Q3. 왜 integer range 0 to 9999처럼 정수를 썼나요?

코드가 읽기 쉽고, 범위만 적어 주면 합성할 때 필요한 비트 수(여기서는 14비트)로 알아서 만들어지기 때문입니다. 자릿수 분리(/, mod)도 정수로 하면 간단합니다.

Q4. 음수는 어떻게 처리했나요?

a가 b보다 작으면 큰 수에서 작은 수를 뺀(b - a) 값을 result에 넣고, neg 신호를 1로 켭니다. 표시 단계에서 neg가 1이면 HEX3에 -를 띄웁니다. 2의 보수 대신 "크기 + 부호"로 나눈 방식입니다.

Q5. 프로세스 맨 위에서 기본값을 먼저 넣는 이유는?

어떤 경우에도 모든 신호에 값이 정해지게 하려는 것입니다. 값이 정해지지 않는 경우가 생기면 회로가 이전 값을 기억하는 래치를 만들 수 있습니다. 표시 프로세스에서는 "먼저 전부 끄고 필요한 칸만 덮어쓰기" 용도로도 씁니다.

Q6. 0으로 나누면 어떻게 되나요?

err 신호가 1이 되어 Err를 표시하고, 나눗셈 자체는 b가 0이 아닐 때만 계산합니다.

Q7. 나머지는 어떻게 구하나요?

몫 q를 구한 뒤 나머지 = a - q × b로 계산합니다. 7 ÷ 3이면 q = 2이고 나머지는 7 - 6 = 1입니다.

Q8. 16진수 표시는 어떻게 했나요?

SW3이 1이면 10으로 나누던 부분을 16으로 나눕니다. result / 16이 윗자리, result mod 16이 아랫자리입니다. seg7에 10~15의 패턴(A, b, C, d, E, F)이 들어 있어서 이 값들이 문자로 보입니다.

Q9. 777 잭팟은 어떻게 구현했나요?

cnt = 777인지 비교합니다. 참이면 초록 LED(LEDG) 8개를 모두 켜고, 표시 프로세스에서 HEX7~4에 7을 넣어 7777을 띄웁니다. 777에서 벗어나면 꺼집니다.

Q10. 두 버튼을 동시에 누르면요?

if / elsif 순서의 우선순위(KEY0 → KEY3 → KEY2 → KEY1)대로 하나만 동작합니다. 같은 클럭 안에서 정확히 동시에 눌렸을 때의 이야기이고, 실제로는 약간씩 시간 차가 있어 따로 인식됩니다.

Q11. 9999에서 더 올리면요? 0에서 내리면요?

9999를 넘기는 경우 9999로 고정하고, 0 아래로 내려가는 경우 0으로 고정합니다. (예: 9995에서 +10 → 9999, 2에서 -5 → 0)

Q12. 카운터는 클럭을 쓰는데 계산기는 왜 안 쓰나요?

카운터는 값을 기억하고 버튼을 누른 순간을 감지해야 해서 클럭에 맞춰 동작하는 순차회로입니다. 계산기는 스위치 값으로만 결과가 정해지고 기억할 필요가 없어서 입력이 바뀌면 바로 반응하는 조합회로입니다.

Q13. 신호(signal)와 변수(variable)는 뭐가 다른가요?

신호는 <=로 대입하고, 프로세스가 끝난 뒤에 값이 바뀝니다. 변수는 :=로 대입하고, 즉시 바뀝니다. 몫 q를 계산하자마자 바로 나머지 계산에 써야 해서 변수를 썼습니다.

Q14. 7세그먼트는 왜 0일 때 켜지나요?

DE2 보드의 7세그먼트는 active-low 방식이라 해당 획에 0을 주면 켜지고 1을 주면 꺼지기 때문입니다. 숫자 0은 g만 끄면 되므로 "1000000"입니다.

Q15. 십진수 모드에서 A나 B가 10 이상이면 어떻게 되나요?

"한 자리 계산기"이므로 십진수 모드에서는 0~9만 표시합니다. 10 이상이면 그 입력 칸이 비고 valid가 0이 되어 결과 칸도 모두 비워집니다. SW3을 1로 올려 16진수 모드로 바꾸면 0~F를 모두 입력할 수 있습니다.

13. 시연 순서 (제안)

  1. 카운터 (SW0 = 0) : 0000 확인 → KEY3을 길게 눌러도 +1만 되는지 → KEY2 → KEY1 → SW1을 올려 +5 / +10 / -5 → KEY0 리셋.
  2. LED : 값이 바뀔 때 빨간 LED가 이진수로 바뀌는지 확인.
  3. 잭팟 : 777을 만들면(예: SW1을 올려 KEY2로 +10을 77번, SW1을 내려 KEY3으로 +1을 7번) 초록 LED 전부 + HEX7~4에 7777.
  4. 계산기 (SW0 = 1) : A = 7, B = 3으로 덧셈 → 뺄셈 → 곱셈 → 나눗셈(2 r1). A와 B를 바꿔 -004, B = 0으로 Err.
  5. 16진수 (SW3 = 1) : A = 15, B = 15로 곱셈 → E1. SW3을 내려 십진수로 돌아가고, A에 10 이상을 넣어 입력과 결과가 빈칸이 되는 것까지 확인.

부록. 전체 코드

1-- DE2 Design Project #1 : Counter + One Digit Calculator (with bonus)
2-- SW0 : 0 = counter, 1 = calculator
3-- Counter    : SW1 = mode, KEY3/KEY2/KEY1 = change value, KEY0 = reset
4--              HEX3~0 = value, LEDR = value in binary
5--              jackpot at 777 : green LEDs on and HEX7~4 show 7777
6-- Calculator : SW17~14 = A, SW13~10 = B, SW2~1 = operation (00 +, 01 -, 10 *, 11 /)
7--              SW3 = 0 : decimal (0~9),  SW3 = 1 : hexadecimal (0~F)
8--              A on HEX6, B on HEX4, result on HEX3~0
9--              division shows "quotient r remainder", for example 7 / 3 -> "2 r1"
10library ieee;
11use ieee.std_logic_1164.all;
12use ieee.numeric_std.all;
13
14entity DE2_Project1 is
15    port (
16        CLOCK_50 : in  std_logic;
17        KEY      : in  std_logic_vector(3 downto 0);
18        SW       : in  std_logic_vector(17 downto 0);
19        LEDR     : out std_logic_vector(17 downto 0);
20        LEDG     : out std_logic_vector(7 downto 0);
21        HEX0, HEX1, HEX2, HEX3, HEX4, HEX5, HEX6, HEX7 : out std_logic_vector(6 downto 0)
22    );
23end DE2_Project1;
24
25architecture behavior of DE2_Project1 is
26    -- character codes : 0~15 = hex digit 0~F, 16 = blank, 17 = '-', 18 = 'r'
27    constant BLANK : integer := 16;
28    constant MINUS : integer := 17;
29    constant CH_R  : integer := 18;
30    constant CH_E  : integer := 14;   -- same shape as hex E
31
32    signal k1, k2 : std_logic_vector(3 downto 0) := "1111";  -- buttons now / one clock ago
33    signal cnt    : integer range 0 to 9999 := 0;            -- counter value
34    signal s1, s2 : integer range 0 to 10;                   -- step size
35    signal a, b   : integer range 0 to 15;                   -- calculator inputs
36    signal result : integer range 0 to 255;                  -- result of + - * (absolute value)
37    signal quot   : integer range 0 to 15;                   -- quotient
38    signal remain : integer range 0 to 15;                   -- remainder
39    signal neg    : std_logic;                               -- 1 = negative result
40    signal err    : std_logic;                               -- 1 = divide by zero
41    signal valid  : std_logic;                               -- 0 = decimal mode and A or B is 10 or more
42    signal d0, d1, d2, d3, d4, d5, d6, d7 : integer range 0 to 18;  -- what each HEX shows
43
44    -- character code -> 7-segment pattern (a segment lights up when 0)
45    function seg7(c : integer) return std_logic_vector is
46    begin
47        case c is
48            when 0  => return "1000000";
49            when 1  => return "1111001";
50            when 2  => return "0100100";
51            when 3  => return "0110000";
52            when 4  => return "0011001";
53            when 5  => return "0010010";
54            when 6  => return "0000010";
55            when 7  => return "1111000";
56            when 8  => return "0000000";
57            when 9  => return "0010000";
58            when 10 => return "0001000";   -- A
59            when 11 => return "0000011";   -- b
60            when 12 => return "1000110";   -- C
61            when 13 => return "0100001";   -- d
62            when 14 => return "0000110";   -- E
63            when 15 => return "0001110";   -- F
64            when 17 => return "0111111";   -- -
65            when 18 => return "0101111";   -- r
66            when others => return "1111111";   -- blank
67        end case;
68    end function;
69begin
70    -- counter : change the value only at the moment a button is pressed (1 -> 0)
71    s1 <= 1 when SW(1) = '0' else 5;     -- step of button1 (+) and button3 (-)
72    s2 <= 2 when SW(1) = '0' else 10;    -- step of button2 (+)
73
74    process (CLOCK_50)
75    begin
76        if rising_edge(CLOCK_50) then
77            k1 <= KEY;
78            k2 <= k1;
79            if SW(0) = '0' then          -- counter mode only
80                if k2(0) = '1' and k1(0) = '0' then          -- KEY0 : reset
81                    cnt <= 0;
82                elsif k2(3) = '1' and k1(3) = '0' then       -- KEY3 : up by s1
83                    if cnt + s1 > 9999 then cnt <= 9999; else cnt <= cnt + s1; end if;
84                elsif k2(2) = '1' and k1(2) = '0' then       -- KEY2 : up by s2
85                    if cnt + s2 > 9999 then cnt <= 9999; else cnt <= cnt + s2; end if;
86                elsif k2(1) = '1' and k1(1) = '0' then       -- KEY1 : down by s1
87                    if cnt < s1 then cnt <= 0; else cnt <= cnt - s1; end if;
88                end if;
89            end if;
90        end if;
91    end process;
92
93    -- LEDs (counter mode only) : red = value in binary, green = jackpot at 777
94    LEDR(13 downto 0)  <= std_logic_vector(to_unsigned(cnt, 14)) when SW(0) = '0' else (others => '0');
95    LEDR(17 downto 14) <= "0000";
96    LEDG <= (others => '1') when SW(0) = '0' and cnt = 777 else (others => '0');
97
98    -- calculator : 00 add, 01 subtract, 10 multiply, 11 divide
99    a <= to_integer(unsigned(SW(17 downto 14)));
100    b <= to_integer(unsigned(SW(13 downto 10)));
101    err <= '1' when SW(2 downto 1) = "11" and b = 0 else '0';
102    valid <= '1' when SW(3) = '1' or (a < 10 and b < 10) else '0';
103
104    process (SW, a, b)
105        variable q : integer range 0 to 15;
106    begin
107        result <= 0;
108        quot <= 0;
109        remain <= 0;
110        neg <= '0';
111        case SW(2 downto 1) is
112            when "00" => result <= a + b;
113            when "01" =>
114                if a >= b then
115                    result <= a - b;
116                else
117                    result <= b - a;     -- a is smaller : calculate b - a and mark negative
118                    neg <= '1';
119                end if;
120            when "10" => result <= a * b;
121            when others =>
122                if b /= 0 then
123                    q := to_integer(to_unsigned(a, 4) / to_unsigned(b, 4));
124                    quot <= q;
125                    remain <= a - q * b;     -- remainder = a - quotient * b
126                end if;
127        end case;
128    end process;
129
130    -- decide what each 7-segment shows
131    process (SW, cnt, a, b, result, quot, remain, neg, err, valid)
132    begin
133        d7 <= BLANK; d6 <= BLANK; d5 <= BLANK; d4 <= BLANK;     -- everything off first
134        d3 <= BLANK; d2 <= BLANK; d1 <= BLANK; d0 <= BLANK;
135
136        if SW(0) = '0' then              -- counter : thousands, hundreds, tens, ones
137            d3 <= cnt / 1000;
138            d2 <= (cnt / 100) mod 10;
139            d1 <= (cnt / 10) mod 10;
140            d0 <= cnt mod 10;
141            if cnt = 777 then            -- jackpot : show 7777
142                d7 <= 7; d6 <= 7; d5 <= 7; d4 <= 7;
143            end if;
144        else                             -- calculator
145            if SW(3) = '1' or a < 10 then d6 <= a; end if;   -- decimal mode shows 0~9 only
146            if SW(3) = '1' or b < 10 then d4 <= b; end if;
147            if valid = '1' then
148                if err = '1' then                            -- divide by zero : " Err"
149                    d2 <= CH_E;  d1 <= CH_R;  d0 <= CH_R;
150                elsif SW(2 downto 1) = "11" then             -- division : "quotient r remainder"
151                    d3 <= quot;  d1 <= CH_R;  d0 <= remain;
152                else
153                    if neg = '1' then d3 <= MINUS; end if;
154                    if SW(3) = '1' then                      -- hexadecimal result : 2 digits
155                        d1 <= result / 16;
156                        d0 <= result mod 16;
157                    else                                     -- decimal result : 3 digits
158                        d2 <= result / 100;
159                        d1 <= (result / 10) mod 10;
160                        d0 <= result mod 10;
161                    end if;
162                end if;
163            end if;
164        end if;
165    end process;
166
167    HEX0 <= seg7(d0);  HEX1 <= seg7(d1);  HEX2 <= seg7(d2);  HEX3 <= seg7(d3);
168    HEX4 <= seg7(d4);  HEX5 <= seg7(d5);  HEX6 <= seg7(d6);  HEX7 <= seg7(d7);
169end behavior;
