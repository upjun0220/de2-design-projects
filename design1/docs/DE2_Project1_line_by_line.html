DE2 Design Project #1 — 줄별 설명

카운터 + 한 자리 계산기 (보너스 포함) · design1/src/DE2_Project1.vhd 138줄 · 발표 준비용

머리말 주석라이브러리와 입출력 핀선언부 — 상수, 신호, 표카운터LED와 잭팟 판정계산기7세그 표시 결정출력 연결주석이 있던 원본예상 질문알아둘 점
전체 흐름
  1. 입력: 스위치 SW와 버튼 KEY를 읽는다. SW0이 카운터/계산기를 고른다.
  2. 카운터 모드: 버튼을 누르는 순간 cnt가 바뀐다(0~9999). 계산기 모드: 스위치 값으로 매번 다시 계산한다.
  3. 표시: 결과를 문자 코드로 바꿔 7세그(HEX)와 LED(LEDR/LEDG)에 내보낸다. 777이면 잭팟 효과가 나온다.

머리말 주석

코드에서는 지웠고, 사용법을 요약해 둔 주석이었다. 원문을 그대로 보여 준다.

코드에서 삭제한 주석 (원문)
-- DE2 Design Project #1 : Counter + One Digit Calculator (with bonus)
과제 이름과 보너스 포함 여부. --로 시작하는 줄은 주석이라 회로에 영향이 없다.
코드에서 삭제한 주석 (원문)
-- SW0 : 0 = counter, 1 = calculator
SW0이 카운터/계산기를 고르는 스위치다. 0이면 카운터, 1이면 계산기.
코드에서 삭제한 주석 (원문)
-- Counter    : SW1 = mode, KEY3/KEY2/KEY1 = change value, KEY0 = reset
--              HEX3~0 = value, LEDR = value in binary
--              jackpot at 777 : green LEDs flash, HEX7~4 show 7777
카운터 모드 요약. SW1은 증감 크기를 고르고(0: +1/+2/-1, 1: +5/+10/-5), KEY3/KEY2/KEY1이 값을 바꾸고 KEY0이 0으로 리셋한다. 값은 HEX3~0에 십진수로, LEDR에 이진수로 나온다. 값이 777이면 잭팟.
코드에서 삭제한 주석 (원문)
-- Calculator : SW17~14 = A, SW13~10 = B, SW2~1 = operation (00 +, 01 -, 10 *, 11 /)
--              SW3 = 0 : decimal (0~9),  SW3 = 1 : hexadecimal (0~F)
--              A on HEX6, B on HEX4, result on HEX3~0
--              division shows "quotient r remainder", for example 7 / 3 -> "2 r1"
계산기 모드 요약. A는 SW17~14, B는 SW13~10(각 4비트), 연산은 SW2~1(00 덧셈, 01 뺄셈, 10 곱셈, 11 나눗셈). SW3=0이면 십진수(0~9), 1이면 16진수(0~F). A는 HEX6, B는 HEX4, 결과는 HEX3~0. 나눗셈은 몫 r 나머지 형태.

선언부 — 상수, 신호, 표

begin(43줄) 앞까지는 회로를 만들기 전에 필요한 이름을 선언하는 곳이다.

16줄
16architecture behavior of DE2_Project1 is
architecture: entity가 실제로 어떻게 동작하는지 쓰는 본문.
17~20줄
17    constant BLANK : integer := 16;
18    constant MINUS : integer := 17;
19    constant CH_R  : integer := 18;
20    constant CH_E  : integer := 14;
7세그에 보낼 '문자 코드'를 정한다. 0~15는 16진수 숫자 그대로, 16은 빈칸, 17은 '-', 18은 'r'. CH_E는 'E'를 16진수 E(14)와 같은 모양으로 쓰기 위한 이름이다.

25줄

26줄

상태 신호: neg는 뺄셈 결과가 음수, err는 0으로 나눔, valid는 십진 모드에서 A나 B가 10 이상이면 0.

seg_table: 길이 19짜리 표 타입. 한 칸이 7비트다.

35    constant SEG7 : seg_table := (

37        "0010010", "0000010", "1111000", "0000000", "0010000",

카운터

버튼을 누르는 순간 한 번만 값이 바뀌고 0~9999에서 멈춘다.

44~45줄
44    s1 <= 1 when SW(1) = '0' else 5;
45    s2 <= 2 when SW(1) = '0' else 10;
증감 크기를 고른다. when ... else는 조건에 따라 값을 고르는 대입문이다. SW1=0이면 s1=1, s2=2, SW1=1이면 s1=5, s2=10.
47~48줄
47    process (CLOCK_50)
48    begin
process (CLOCK_50): 클럭 신호가 바뀔 때 실행되는 블록.
49줄
49        if rising_edge(CLOCK_50) then
rising_edge: 클럭이 0→1로 올라가는 순간에만 안쪽을 실행한다(동기 회로).
50~51줄
50            k1 <= KEY;
51            k2 <= k1;
버튼을 두 단계로 받는다. 매 클럭 k1=지금 KEY, k2=한 클럭 전 k1. 그래서 k2='1' and k1='0'이면 '방금 눌렸다(1→0)'는 뜻이다. 길게 눌러도 한 번만 세는 이유다.
52줄
52            tick <= tick + 1;
tick을 매 클럭 1 증가.
53줄
53            if SW(0) = '0' then
계산기 모드에서는 카운터가 변하지 않도록 SW(0)='0'일 때만 아래를 실행한다.
54~55줄
54                if k2(0) = '1' and k1(0) = '0' then
55                    cnt <= 0;
KEY0을 누르는 순간 0으로 리셋. elsif 체인이라 우선순위는 KEY0 > KEY3 > KEY2 > KEY1이다. 이 우선순위는 두 에지가 같은 클럭(20 ns)에 겹칠 때만 적용된다. 손으로 누르면 보통 몇 ms 어긋나서 두 에지가 따로 잡히고, 나중에 잡힌 쪽이 마지막에 반영된다.
56~57줄
56                elsif k2(3) = '1' and k1(3) = '0' then
57                    if cnt + s1 > 9999 then cnt <= 9999; else cnt <= cnt + s1; end if;
KEY3: s1만큼 증가. cnt + s1 > 9999이면 9999에 고정(포화).
58~59줄
58                elsif k2(2) = '1' and k1(2) = '0' then
59                    if cnt + s2 > 9999 then cnt <= 9999; else cnt <= cnt + s2; end if;
KEY2: s2만큼 증가, 같은 포화 처리.
60~61줄
60                elsif k2(1) = '1' and k1(1) = '0' then
61                    if cnt < s1 then cnt <= 0; else cnt <= cnt - s1; end if;
KEY1: s1만큼 감소. 0보다 작아지면 0에 고정.
62~65줄
62                end if;
63            end if;
64        end if;
65    end process;
열려 있던 if와 process를 닫는다.

LED와 잭팟 판정

빨간 LED는 항상 이진수 표시, 777이면 초록 LED만 번쩍인다.

67줄
67    jp   <= '1' when SW(0) = '0' and cnt = 777 else '0';
잭팟 판정: 카운터 모드이고 값이 777일 때 jp=1.
68줄
68    LEDR <= std_logic_vector(to_unsigned(cnt, 18)) when SW(0) = '0' else (others => '0');
LEDR: 카운터 모드이면 cnt를 18비트 이진수로 바꿔 출력한다(최대 9999는 14비트라 위 4개는 0). 잭팟(777)일 때도 똑같이 이진수를 보여 준다. 계산기 모드면 전부 0.
69줄
69    LEDG <= (others => tick(23)) when jp = '1' else (others => '0');
LEDG: 잭팟이면 8개가 모두 tick(23)을 따라 켜졌다 꺼진다(번쩍, 약 0.17초 간격). 아니면 꺼진다.

계산기

스위치 값이 바뀔 때마다 다시 계산하는 조합 회로다.

71~72줄
71    a <= to_integer(unsigned(SW(17 downto 14)));
72    b <= to_integer(unsigned(SW(13 downto 10)));
SW(17 downto 14)를 unsigned로 보고 to_integer로 정수 0~15를 만든다. 이것이 A, 같은 식으로 SW13~10이 B.
73줄
73    err <= '1' when SW(2 downto 1) = "11" and b = 0 else '0';
나눗셈(SW2~1=11)인데 B=0이면 err=1.
74줄
74    valid <= '1' when SW(3) = '1' or (a < 10 and b < 10) else '0';
16진수 모드(SW3=1)이거나 A, B가 모두 10 미만이면 유효. 십진 모드에서 10 이상이면 무효.
76~77줄
76    process (SW, a, b)
77    begin
계산 process. 괄호 안은 감지 목록으로, SW, a, b가 바뀔 때마다 다시 계산한다.
78~81줄
78        result <= 0;
79        quot <= 0;
80        remain <= 0;
81        neg <= '0';
먼저 모든 결과를 기본값으로 둔다. 어떤 경우에도 값이 정해지므로 불필요한 래치가 생기지 않는다.
82줄
82        case SW(2 downto 1) is
case SW(2 downto 1): 연산 선택.
83줄
83            when "00" => result <= a + b;
00 덧셈.
84~90줄
84            when "01" =>
85                if a >= b then
86                    result <= a - b;
87                else
88                    result <= b - a;
89                    neg <= '1';
90                end if;
01 뺄셈. A≥B이면 a-b. 작으면 b-a를 계산하고 neg=1로 표시해 둔다(음수 기호는 표시 단계에서 붙인다).
91줄
91            when "10" => result <= a * b;
10 곱셈.
92~96줄
92            when others =>
93                if b /= 0 then
94                    quot <= a / b;
95                    remain <= a mod b;
96                end if;
11 나눗셈. B≠0일 때만 한다. 몫은 a / b(소수점 아래는 버림), 나머지는 a mod b로 구한다. 표시 단계의 /, mod와 같은 연산이다.
97~98줄
97        end case;
98    end process;
case와 process를 닫는다.

100~101줄
100    process (SW, cnt, a, b, result, quot, remain, neg, err, valid)
101    begin
표시 내용을 정하는 process. 값이 바뀌면 다시 계산하는 조합 회로.
102~103줄
102        d7 <= BLANK; d6 <= BLANK; d5 <= BLANK; d4 <= BLANK;
103        d3 <= BLANK; d2 <= BLANK; d1 <= BLANK; d0 <= BLANK;
먼저 8칸 모두 빈칸으로 두고 시작한다. 아래에서 필요한 칸만 덮어쓴다.
105줄
105        if SW(0) = '0' then
카운터 모드.
106~109줄
106            d3 <= cnt / 1000;
107            d2 <= (cnt / 100) mod 10;

값을 자릿수로 쪼갠다. 예) 1234 → /1000=1, /100 mod 10=2, /10 mod 10=3, mod 10=4. HEX3(천)~HEX0(일).
110~112줄
110            if cnt = 777 then
111                d7 <= 7; d6 <= 7; d5 <= 7; d4 <= 7;
112            end if;
잭팟(777)이면 HEX7~4에 7을 4개 띄운다.
113줄
113        else
계산기 모드.
114~115줄
114            if SW(3) = '1' or a < 10 then d6 <= a; end if;
115            if SW(3) = '1' or b < 10 then d4 <= b; end if;
A는 HEX6, B는 HEX4에 표시. 십진 모드에서 10 이상이면 빈칸으로 둔다.
116줄
116            if valid = '1' then
입력이 유효할 때만 결과를 표시한다.
117~118줄
117                if err = '1' then

0으로 나눔: HEX2~0에 ' Err'(E, r, r).
119~120줄
119                elsif SW(2 downto 1) = "11" then

나눗셈: HEX3=몫, HEX1='r', HEX0=나머지. 예) 7÷3 → 2 r1.
121~122줄
121                else

126                    else

주석이 있던 원본

저장소의 코드에는 주석이 없다. 지운 주석을 포함한 원본(153줄)이다.

펼치기
1-- DE2 Design Project #1 : Counter + One Digit Calculator (with bonus)
2-- SW0 : 0 = counter, 1 = calculator
3-- Counter    : SW1 = mode, KEY3/KEY2/KEY1 = change value, KEY0 = reset
4--              HEX3~0 = value, LEDR = value in binary
5--              jackpot at 777 : green LEDs flash, HEX7~4 show 7777
6-- Calculator : SW17~14 = A, SW13~10 = B, SW2~1 = operation (00 +, 01 -, 10 *, 11 /)
7--              SW3 = 0 : decimal (0~9),  SW3 = 1 : hexadecimal (0~F)
8--              A on HEX6, B on HEX4, result on HEX3~0
9--              division shows "quotient r remainder", for example 7 / 3 -> "2 r1"
10library ieee;
11use ieee.std_logic_1164.all;
12use ieee.numeric_std.all;
13
14entity DE2_Project1 is
15    port (
16        CLOCK_50 : in  std_logic;
17        KEY      : in  std_logic_vector(3 downto 0);
18        SW       : in  std_logic_vector(17 downto 0);
19        LEDR     : out std_logic_vector(17 downto 0);
20        LEDG     : out std_logic_vector(7 downto 0);
21        HEX0, HEX1, HEX2, HEX3, HEX4, HEX5, HEX6, HEX7 : out std_logic_vector(6 downto 0)
22    );
23end DE2_Project1;
24
25architecture behavior of DE2_Project1 is
26    -- character codes : 0~15 = hex digit 0~F, 16 = blank, 17 = '-', 18 = 'r'
27    constant BLANK : integer := 16;
28    constant MINUS : integer := 17;
29    constant CH_R  : integer := 18;
30    constant CH_E  : integer := 14;   -- same shape as hex E
31
32    signal k1, k2 : std_logic_vector(3 downto 0) := "1111";  -- buttons now / one clock ago
33    signal cnt    : integer range 0 to 9999 := 0;            -- counter value
34    signal s1, s2 : integer range 0 to 10;                   -- step size
35    signal a, b   : integer range 0 to 15;                   -- calculator inputs
36    signal result : integer range 0 to 255;                  -- result of + - * (absolute value)
37    signal quot   : integer range 0 to 15;                   -- quotient
38    signal remain : integer range 0 to 15;                   -- remainder
39    signal neg    : std_logic;                               -- 1 = negative result
40    signal err    : std_logic;                               -- 1 = divide by zero
41    signal valid  : std_logic;                               -- 0 = decimal mode and A or B is 10 or more
42    signal d0, d1, d2, d3, d4, d5, d6, d7 : integer range 0 to 18;  -- what each HEX shows
43
44    -- 7-segment pattern of each character code (a segment lights up when 0)
45    type seg_table is array (0 to 18) of std_logic_vector(6 downto 0);
46    constant SEG7 : seg_table := (
47        "1000000", "1111001", "0100100", "0110000", "0011001",   -- 0 1 2 3 4
48        "0010010", "0000010", "1111000", "0000000", "0010000",   -- 5 6 7 8 9
49        "0001000", "0000011", "1000110", "0100001", "0000110", "0001110",   -- A b C d E F
50        "1111111", "0111111", "0101111");                        -- blank - r
51
52    signal tick : unsigned(23 downto 0) := (others => '0');  -- free running counter (LED flash)
53    signal jp   : std_logic;                                 -- 1 = jackpot (counter mode and value 777)
54begin
55    -- counter : change the value only at the moment a button is pressed (1 -> 0)
56    s1 <= 1 when SW(1) = '0' else 5;     -- step of button1 (+) and button3 (-)
57    s2 <= 2 when SW(1) = '0' else 10;    -- step of button2 (+)
58
59    process (CLOCK_50)
60    begin
61        if rising_edge(CLOCK_50) then
62            k1 <= KEY;
63            k2 <= k1;
64            tick <= tick + 1;
65            if SW(0) = '0' then          -- counter mode only
66                if k2(0) = '1' and k1(0) = '0' then          -- KEY0 : reset
67                    cnt <= 0;
68                elsif k2(3) = '1' and k1(3) = '0' then       -- KEY3 : up by s1
69                    if cnt + s1 > 9999 then cnt <= 9999; else cnt <= cnt + s1; end if;
70                elsif k2(2) = '1' and k1(2) = '0' then       -- KEY2 : up by s2
71                    if cnt + s2 > 9999 then cnt <= 9999; else cnt <= cnt + s2; end if;
72                elsif k2(1) = '1' and k1(1) = '0' then       -- KEY1 : down by s1
73                    if cnt < s1 then cnt <= 0; else cnt <= cnt - s1; end if;
74                end if;
75            end if;
76        end if;
77    end process;
78
79    -- LEDs (counter mode only) : red = value in binary, jackpot at 777 : green flash
80    jp   <= '1' when SW(0) = '0' and cnt = 777 else '0';
81    LEDR <= std_logic_vector(to_unsigned(cnt, 18)) when SW(0) = '0' else (others => '0');
82    LEDG <= (others => tick(23)) when jp = '1' else (others => '0');
83
84    -- calculator : 00 add, 01 subtract, 10 multiply, 11 divide
85    a <= to_integer(unsigned(SW(17 downto 14)));
86    b <= to_integer(unsigned(SW(13 downto 10)));
87    err <= '1' when SW(2 downto 1) = "11" and b = 0 else '0';
88    valid <= '1' when SW(3) = '1' or (a < 10 and b < 10) else '0';
89
90    process (SW, a, b)
91    begin
92        result <= 0;
93        quot <= 0;
94        remain <= 0;
95        neg <= '0';
96        case SW(2 downto 1) is
97            when "00" => result <= a + b;
98            when "01" =>
99                if a >= b then
100                    result <= a - b;
101                else
102                    result <= b - a;     -- a is smaller : calculate b - a and mark negative
103                    neg <= '1';
104                end if;
105            when "10" => result <= a * b;
106            when others =>
107                if b /= 0 then
108                    quot <= a / b;
109                    remain <= a mod b;
110                end if;
111        end case;
112    end process;
113
114    -- decide what each 7-segment shows
115    process (SW, cnt, a, b, result, quot, remain, neg, err, valid)
116    begin
117        d7 <= BLANK; d6 <= BLANK; d5 <= BLANK; d4 <= BLANK;     -- everything off first
118        d3 <= BLANK; d2 <= BLANK; d1 <= BLANK; d0 <= BLANK;
119
120        if SW(0) = '0' then              -- counter : thousands, hundreds, tens, ones
121            d3 <= cnt / 1000;
122            d2 <= (cnt / 100) mod 10;
123            d1 <= (cnt / 10) mod 10;
124            d0 <= cnt mod 10;
125            if cnt = 777 then            -- jackpot : show 7777
126                d7 <= 7; d6 <= 7; d5 <= 7; d4 <= 7;
127            end if;
128        else                             -- calculator
129            if SW(3) = '1' or a < 10 then d6 <= a; end if;   -- decimal mode shows 0~9 only
130            if SW(3) = '1' or b < 10 then d4 <= b; end if;
131            if valid = '1' then
132                if err = '1' then                            -- divide by zero : " Err"
133                    d2 <= CH_E;  d1 <= CH_R;  d0 <= CH_R;
134                elsif SW(2 downto 1) = "11" then             -- division : "quotient r remainder"
135                    d3 <= quot;  d1 <= CH_R;  d0 <= remain;
136                else
137                    if neg = '1' then d3 <= MINUS; end if;   -- MINUS = code 17 = '-' (d3 is an integer code, not a character)
138                    if SW(3) = '1' then                      -- hexadecimal result : 2 digits
139                        d1 <= result / 16;
140                        d0 <= result mod 16;
141                    else                                     -- decimal result : 3 digits
142                        d2 <= result / 100;
143                        d1 <= (result / 10) mod 10;
144                        d0 <= result mod 10;
145                    end if;
146                end if;
147            end if;
148        end if;
149    end process;
150
151    HEX0 <= SEG7(d0);  HEX1 <= SEG7(d1);  HEX2 <= SEG7(d2);  HEX3 <= SEG7(d3);
152    HEX4 <= SEG7(d4);  HEX5 <= SEG7(d5);  HEX6 <= SEG7(d6);  HEX7 <= SEG7(d7);
153end behavior;

발표 예상 질문

코드를 보지 않고 답해 보면 좋은 질문.

버튼을 길게 눌러도 왜 한 번만 오르나?

50~51줄에서 버튼을 두 클럭에 걸쳐 저장하고, 53~60줄이 k2='1' and k1='0'(1→0으로 바뀐 순간)에만 값을 바꾼다. 누르고 있는 동안은 k2와 k1이 모두 0이라 조건이 거짓이다.

뺄셈이 음수면 어떻게 처리하나?

84~90줄에서 큰 수에서 작은 수를 빼서 result에 절댓값을 넣고 neg를 1로 둔다. 표시 단계(121~122줄)가 HEX3에 '-'를 붙인다.

나머지는 어떻게 구하나?

92~96줄: 몫은 a / b, 나머지는 a mod b로 구한다.

16진수 결과는 어떻게 두 자리로 나누나?

123~125줄: 결과를 16으로 나눈 몫이 HEX1, 나머지가 HEX0. 225는 14와 1이라서 E1이다.

동시에 버튼 두 개를 누르면?

53~60줄이 elsif 체인이라 KEY0 > KEY3 > KEY2 > KEY1 순서로 하나만 적용되지만, 이것은 두 눌림이 같은 클럭(20 ns)에 겹칠 때만이다. 손으로 누르면 몇 ms 어긋나서 두 에지가 따로 잡혀 둘 다 적용된다. 예) KEY3과 KEY2를 거의 동시에 누르면 +1 후 +2로 +3, KEY3을 먼저 누르고 KEY0을 누르면 0, KEY0을 먼저 누르고 KEY3을 누르면 1(보드에서 확인). 동시 입력에 대한 규칙은 과제에 따로 없다.

777일 때 LEDR의 이진수 표시는 어떻게 되나?

68~69줄: 잭팟이어도 LEDR은 계속 이진수(777 = 1100001001)를 보여 주고, 초록 LED(LEDG)만 tick(23)을 따라 번쩍인다.

integer와 unsigned는 왜 나눠 쓰나?

integer는 범위만 정하면 되는 숫자라서 계산과 비교(/, mod, >)에 쓴다(cnt, a, b). unsigned는 비트 묶음을 음수 없는 숫자로 보는 타입이라 한 비트만 꺼내 쓰거나(tick(23)) 스위치 비트를 숫자로 바꿀 때 쓴다.

mod 10은 무슨 뜻인가?

10으로 나눈 나머지, 즉 십진수의 마지막 자리다. cnt mod 10이 일의 자리, (cnt / 10) mod 10이 십의 자리다.

MINUS를 놔두고 '-'를 쓰면 안 되나?

d3는 문자 코드(정수 0~18)를 담는 신호라서 문자 '-'를 넣을 수 없다. MINUS는 코드 17이고, 7세그 표 17번 칸이 '-' 모양이다.

HEX7~4에 7777은 왜 띄우나?

카운터 모드에서 쓰지 않는 왼쪽 네 칸을 잭팟 연출에 쓴다. 777일 때만 d7~d4를 7로 덮어쓴다.

알아둘 점

  • 시뮬레이션(ModelSim)에서 카운터, 계산기 전 조합, LED 점멸을 2130개 검사해 통과했다. 보드 동작은 확인하지 않았다.
