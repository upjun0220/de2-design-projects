DE2 마법 펜 — VGA 화면 설계안 (2판: 간소화)

작성 2026-11-11 · 1판이 난잡하다는 의견에 따라 다시 설계했다. 보드 코드(hdl/vga_ui.v, nios/ui.c)는 아직 1판 구성이다. 이 2판이 확정되면 옮긴다. 화면의 숫자는 모두 예시 값이다(DTW 시간은 시뮬레이션 값).

1판에서 바꾼 것

문제2판
패널 5개(PEN, SENSORS, MATCH, 결과, DTW)가 항상 같이 떠 있었다식별·등록 화면에는 상태, 근거, 펜, DTW 시간만 둔다. 높이·기울기·속도는 서명하는 동안에만 상태 아래에 게이지(막대)로 나온다. 기울기 방향은 2배 크기 화살표다. 센서 값은 데이터 수집 모드(SW1-0 = 10)에만 나온다
결과가 다른 정보와 같은 크기였다상태를 2배 크기 글자로 쓴다. 한 화면에 큰 글자는 이것 하나다
색이 7가지였다회색 글자가 기본이고, 색은 뜻이 있을 때만 쓴다: 초록 = 등록자·펜 내림, 빨강 = 미등록·오류, 노랑 = 문턱 눈금
제목 줄에 항목 5개, 아래에 안내 2줄과 상태 줄제목 줄은 이름과 모드만. 안내는 지금 모드에서 쓰는 키만 한 줄
등록 안 된 슬롯, 빈 막대까지 모두 그렸다거리 막대는 결과가 나왔을 때 등록된 사람만 그린다
서명 칸에 종이 점선, 치수 글자서명 기준선과 x 표시만 남겼다
DTW 시간을 로그 막대 2개로숫자 두 개와 배수 한 줄. 지금 쓰는 쪽(SW5)을 밝게 표시한다

하드웨어 제약 (그대로 옮길 수 있는 것만 쓴다)

  • 문자 층: 80×30칸(칸 하나가 8×16픽셀), 칸마다 글자 + 글자색 + 배경색. 막대는 1/8칸 단위의 조각 글자로 그린다.
  • 2배 글자(새로 필요): 글자 바이트의 남는 비트 하나를 "2배" 표시로 쓴다. 같은 글자를 2×2칸에 쓰면 각 칸이 글자의 1/4씩을 그린다. 어느 1/4인지는 칸 위치의 짝·홀로 정하므로 메모리가 늘지 않고 선택 회로만 조금 늘어난다(구현 전, 추정).
  • 비트맵 층: 서명 칸 192×192픽셀 1비트(화면에서 2배). 1픽셀 = 0.5 mm, 칸 전체 = 96×96 mm.
  • 펜 커서: 십자 하나. 펜을 내리면 초록, 들면 회색.
  • 화면 글자는 영문만 쓴다. 결과는 PERSON n 또는 NOT ENROLLED이고, 인증·보안·위조 판별을 뜻하는 말은 쓰지 않는다.

참고한 화면

  • 서명 패드(Wacom STU 계열): 테두리가 분명한 서명 영역, 쓰는 동안 획 표시. Wacom STU-540 서명 캡처 모드
  • 지문 등록 화면: 필요한 횟수를 먼저 알리고 표본마다 바로 알려 준다. Microsoft 지문 등록 지침
