## 0. Claude Code에게: 작업 원칙

- 응답과 주석은 **한국어**. 코드 식별자는 영어. (단 HDL·C 소스 주석은 영어 ASCII — `../CLAUDE.md` 참고.)
- **정직하고 기술적으로 엄밀하게.** 확인한 것과 추정한 것을 구분해서 쓴다. 근거 없는 수치를 확정처럼 쓰지 않는다. 시뮬레이션 숫자를 실측처럼 말하지 않는다.
- **요청한 범위만 수정한다.** 기존 문서·코드의 스타일을 유지하고, 요청하지 않은 리팩터링이나 기능 추가를 하지 않는다.
- 하드웨어 전압은 **3.3 V 로직만** (Cyclone II는 5 V 비내성). 5 V를 연결하는 코드·배선 제안을 하지 않는다.
- 서명 데이터는 개인정보다. 파일명은 이름 대신 번호를 쓰고, 수집 전 동의가 전제다.

## 1. 프로젝트 요약

- **과목:** 숭실대 마이크로프로세서 자유주제 팀 프로젝트(2인), 약 1개월. 준비 기간 11/2~11/22, 리허설 11/20(금).
- **보드:** Altera DE2 (Cyclone II EP2C35F672C6), Quartus II 13.0 SP1, Qsys, Nios II EDS. 23개 팀이 같은 보드를 쓰므로 창의성이 평가에 중요하다.
- **교수님 방침(전달받은 내용):** 주제 자유, AI 최대한 활용, 창의성 가점. VHDL 필수 아님. 오실로스코프 대여 가능.
- **팀 요구:** 전기공학 요소 필수, AI가 강점이어야 함, "DE2로 이런 것도 되네" 느낌. 게임·단순 키→소리·전류/전압 측정류 제외.
- **주제:** 펜 끝 영구자석의 자기장을 3축 자기 센서 배열로 읽어 펜의 3차원 위치·기울기를 복원하고, 서명 한 번의 시계열로 **누가 썼는지 식별**한다. 등록자면 이름, 아니면 "미등록".
- **범위 주의:** "서명 **인증**·보안" 장치가 아니다. 위조 서명을 걸러낸다고 주장하지 않는다. 위조(따라 쓰기) 실험은 한계를 정량으로 보고하는 용도다.
- **AI 요소:** (1) 위치 복원 MLP, (2) 서명 임베딩 1D CNN. 같은 int8 모델을 Nios II 소프트웨어와 병렬 MAC 하드웨어로 구현해 지연·LE·곱셈기 사용량을 비교하는 것이 수업의 핵심이다.

## 3. 시스템 구성

```
자석 펜 ─(자기장)→ MLX90393 ×4 ─I²C→ [I²C 마스터(Verilog)] → 샘플 FIFO
  → 기준값 차감(KEY0로 재측정) → 위치 MLP → (x, y, z, θ, φ) @ ~50 Hz
  → 서명 버퍼(시작/끝 판정, SDRAM) → 전처리(정규화·128점 리샘플·8채널 int8)
  → 임베딩 1D CNN(32차원)  +  DTW(기준선)  → 판정(등록자 ID / 미등록)
  → LCD(영문), VGA(한글·2D 서명·3D 궤적), LED, 7세그(추론 지연)
PC(오프라인): 시뮬레이션·학습·int8 양자화·.hex 출력, JTAG UART로 로그 수신
```

### 3.1 위치 복원

- 모델: 자기 쌍극자 `B = (μ0/4π)[3(m·r̂)r̂ − m]/r³`, m = M0·(sinθcosφ, sinθsinφ, cosθ). 센서 4개 × 3축 = 12개 측정 → 5자유도(x, y, z, θ, φ).
- 펜 축 자체 회전은 관측 불가(필요 없음). 기준값 차감으로 지자기·고정 오프셋을 제거한다(연철 왜곡은 제거 못 함).
- 기준선은 Levenberg–Marquardt 피팅, 다중 시작점은 첫 프레임에서만, 이후는 직전 해로 warm-start. 목표 MLP는 입력 12 → 출력 5 (약 5k MAC 이하, 추정).
- 쌍극자 근사는 자석 크기(10 mm)의 약 3배(30 mm) 이상 거리에서 맞는다. 가까우면 오차가 커진다.

### 3.2 서명 버퍼·전처리

- 프레임 `(t, x, y, z, θ, φ, pen)`, 50 Hz, 최대 6 s(300프레임). `pen`은 z 문턱 + 히스테리시스로 판정.
- 시작: 펜이 처음 내려간 순간. 끝: 펜 올림이 1.0 s 지속되거나 KEY1. 펜 내림 구간 0.5 s 미만이거나 추적 끊김 프레임이 20% 초과면 "다시 서명" 후 폐기.
- 정규화: 펜 내림 점의 무게중심을 원점으로, 가로 폭을 1로. z는 판 기준 높이 그대로.
- 리샘플: 시간축 기준 128점 선형 보간(총 소요 시간은 별도 숫자로 보관). 입력 채널 8개 `x, y, z, vx, vy, θ, φ, pen`, 채널별 스케일로 int8.

### 3.3 임베딩 CNN (초안)

```
입력 128×8
Conv1D  8→16, k=5, ReLU, MaxPool2   → 64×16   (~82k MAC)
Conv1D 16→32, k=5, ReLU, MaxPool2   → 32×32   (~164k MAC)
Conv1D 32→32, k=3, ReLU, MaxPool2   → 16×32   (~98k MAC)
Global Average Pool                  → 32
Dense 32→32 → L2 정규화              → 32차원 임베딩
```

총 약 34.5만 MAC, 가중치 약 7.3k개(int8 약 7 KB). 학습은 triplet 또는 prototypical 손실. 등록은 서명 5개의 임베딩 평균을 기준 벡터로 저장한다.

### 3.4 판정 규칙

```
d_k = 1 − cos(e, ref_k)          # 등록자 k와의 거리
k1, k2 = 거리가 가장 작은 두 등록자
등록자 k1 판정 ⇔ d_k1 < τ_k1  and  (d_k2 − d_k1) ≥ m  and (선택) DTW 동의
τ_k = μ_k + a·σ_k   # 등록 시 본인 서명 5개끼리의 거리 평균·표준편차
```

a, m, τ_dtw는 검증 데이터로 정한다. 미등록을 등록자로 잘못 받는 오류를 줄이는 방향으로 잡는다. DTW는 Sakoe–Chiba 대역 16, 템플릿당 약 4k 셀.

## 4. DE2 / Quartus 사양

- **Qsys 구성:** Nios II(코어 /e·/s·/f는 미결 — SW 추론 속도에 영향), SDRAM, Character LCD IP(University Program), VGA Pixel Buffer(320×240, 백 버퍼), PIO, JTAG UART, 타이머, 병렬 MAC(Avalon, 커스텀).
- **핀(GPIO_0, 3.3 V):** 헤더 29/30 = VCC33/GND, 1/3 = `GPIO_0[0]`/`[2]` = 버스 A SDA/SCL, 12 = GND. 확장 시 5/7(`[4]`/`[6]`), 13/15(`[10]`/`[12]`)는 예시다. **핀 번호는 DE2 User Manual 확장 헤더 그림으로 반드시 재확인.** 헤더가 수 핀이라는 가정은 보드에서 확인.
- **센서 연결:** 4209 케이블(수 핀 끝) → 암-암 점퍼선 → DE2 헤더. 모듈 풀업이 병렬이 되므로 SDA/SCL 파형을 SignalTap·오실로스코프로 확인한다.
- **사용자 인터페이스:** `SW[1:0]` 00 식별 / 01 등록(`SW[4:2]` 슬롯 0~7, 서명 5회) / 10 데이터 수집(JTAG UART로 원시 시계열 전송) · `SW[5]` 추론 SW/HW · `SW[6]` 3D 자동 회전 · `KEY0` 기준 재측정 · `KEY1` 서명 끝 · `KEY2` 마지막 서명 취소. LEDG 전체 = 등록자, LEDR 3회 깜빡임 = 미등록. 7세그 = 추론 지연(µs). LCD는 영문만, 한글 이름은 PC에서 16×16 비트맵으로 만들어 온칩 ROM.
- 미사용 핀: Unused Pins → As input tri-stated.

## 5. 시뮬레이션 코드와 결과 (`sim/`)

| 파일 | 내용 |
|---|---|
| `sim_sensors.py` | 쌍극자 모델, 센서 배치별(4/9/16개) 위치 오차 몬테카를로, LM 다중 시작 |
| `sim_interference.py` | 외란(균일·기울기)이 있을 때 오차, 외란 미지수(nuisance)를 피팅에 넣는 경우 |
| `sim_layout_opt.py` | CRLB 기반 차분 진화로 센서 배치 최적화 + LM 몬테카를로 |
| `sim_sig_tracking.py` | 서명형 궤적(50 Hz, 3 s) 추적, 위치·기울기·속도 오차 |

공통 가정: 노이즈 3 µT(센서당 축마다), M0 = 0.55 A·m²(φ8×10 상당), 기울기 최대 약 47°, 높이 z = 4.5 cm 근처. 교정 오차는 센서 위치 1 mm, 이득 2%.

**결과 (모두 시뮬레이션, 실측 아님):**

- 위치 xy RMS, 기울기 ≤20°: 4개 ±6 cm 2.5 mm / 4개 ±3 cm 1.6 / 9개 1.1 / 16개 0.7. 교정 오차 포함 시 3.2 / 2.8 / 2.3 / 2.2. 기울기를 무시(3자유도)하면 6.7 / 4.9 / 4.5 / 4.4.
- 센서 배치 최적화는 이득이 없었다(음의 결과). 2×2 ±3 cm가 이미 거의 최적: CRLB 1.59 mm, DE 최적 4개 1.58 mm.
- 서명형 궤적 추적(3 s, 50 Hz, 기울기 약 23~47°):

| 배치 | 교정 오차 | xy (mm) | z (mm) | 기울기 (°) | 속도 오차 (%) |
|---|---|---|---|---|---|
| 4개 ±3 cm | 없음 | 0.42 | 0.11 | 1.0 | 0.9 |
| 4개 ±3 cm | 있음 | 1.72 | 0.78 | 3.6 | 4.1 |
| 9개 ±6 cm | 없음 | 0.32 | 0.10 | 0.8 | 0.7 |
| 9개 ±6 cm | 있음 | 1.97 | 0.80 | 3.0 | 3.8 |

- 4개는 외란 기울기(gradient)를 피팅할 수 없다(미지수 13개 > 측정 12개). 균일 외란은 가능.

**한계(중요):**
- 참값 생성과 추정이 같은 쌍극자 모델(inverse crime) → 모델 오차 없음. 실제 자석 비이상성·주변 철 구조물은 미반영.
- **현재 확정 구조(필기면 위 약 36 mm, 자석 약 0.9 A·m²)로는 아직 재시뮬레이션하지 않았다.** 위 결과는 z=4.5 cm, M0=0.55 기준이다.
- 속도 오차는 평활 필터를 거친 참값과의 비교라 필터의 평활 손실은 포함되지 않는다.
- `sim_sig_tracking.py`의 방위각 φ 오차 열은 0으로 고정(기울기 방향 벡터 각도 오차만 의미 있음).

3. 센서 읽기 → UART 로그 → PC에서 위치 복원 LM 기준선 동작 확인(4개 2×2 판).

**P1 — 데이터 수집 전(11/13)**
4. **데이터 수집 모드는 위치 복원 결과뿐 아니라 센서 12채널 원시값도 함께 저장한다.** 11/13 수집이 게이트 2(11/15)보다 먼저라, 나중에 추적기를 개선해도 서명을 다시 계산할 수 있어야 한다. 세션 메타데이터(참가자 번호, 날짜, 역할) 포함.
5. 평가 하네스(Python): DTW 기준선, FAR/FRR/EER, 사람별 혼동행렬, 신뢰구간(위조 n회 중 0회 통과 시 95% 상한 ≈ 3/n).
   - **데이터 분리:** 학습·검증·테스트는 **날짜**로 나누고, 미등록 역할은 **문턱 결정용과 시험용 사람을 분리**한다(같은 사람으로 학습하고 FAR를 재면 낙관적으로 나온다). 인원이 적으면 한 사람씩 빼고 시험(leave-one-person-out).
   - 입력 채널 ablation: (x,y,pen) / +속도 / +z·θ·φ.

**P2 — 모델·하드웨어**
6. 임베딩 CNN 학습(PyTorch 등) → int8 양자화 → 테스트 벡터 100개를 Python / Nios II SW / HW에서 **비트 단위 일치** 검증. `.hex` 출력.
   - 공개 온라인 서명 데이터셋은 x, y, 시간(필압) 정도만 있어 z·θ·φ 채널은 사전학습되지 않는다. 사전학습은 해당 채널을 마스킹하는 식으로 별도 설계. 데이터셋 선정은 라이선스·수업 사용 가능 여부를 먼저 확인.
7. Nios II C: 서명 버퍼, 전처리, DTW, CNN SW 추론, 판정, LCD·VGA·LED. 병렬 MAC 엔진(Avalon)으로 Conv 층 가속, 선택으로 DTW 대역 가속. 자원(LE, 곱셈기, 메모리)·지연(타임스탬프 타이머) 측정표.
8. VGA 3D 표시: 회전·투영(고정소수점 sin/cos 표), Bresenham 선, 백 버퍼, 한글 이름 비트맵.

## 7. 평가 프로토콜 (요약)

- **등록자 식별 정확도** ≥90%(잠정), **FAR** ≤10%, **FRR** ≤15%(내부 목표, 방향 설정용이며 못 미쳐도 실측을 그대로 보고).
- 위협 모델 3종: 랜덤 위조 / 정지 이미지를 보고 따라 쓰기 / 서명 영상(속도·획순)을 보고 따라 쓰기. 위협 모델별로 따로 보고.
- 보고 형식: "위조 N회 중 M회 통과, 95% 신뢰구간 …". "FAR 0%"라고 쓰지 않는다. 같은 위조자가 같은 대상을 여러 번 쓴 시도는 독립이 아니므로 한계에 적는다.
- 비교 항목: DTW 단독 / CNN 단독 / 결합, 입력 채널별, SW 대 HW(지연·LE·곱셈기·온칩 메모리), 비트 일치, 서명 1회 판정 시간(≤1 s, 타임아웃 1 s 제외).
- 참고 문헌 기준선(다른 조건): AirSignatureDB 숙련 위조 EER 2.3%(기준 서명 4개)~8.9%(1개), SVC-onGoing 최고 3.3~7.4%. 사용자 수십~100명 이상 데이터라 우리(8~15명)와 직접 비교하지 않는다.

## 9. 위험과 미확인 사항

- 실측 위치 오차는 시뮬레이션보다 몇 배 클 수 있다(문헌: 센서 16개 실측 약 4 mm). 4개는 간섭 보정 여지가 9개보다 적다.
- 펜 올림/내림 오판(서명은 펜을 짧게 자주 든다). z 히스테리시스 조정, `pen` 대신 z를 직접 입력하는 방안 비교.
- 사람 수가 적으면 임베딩이 처음 보는 사람에게 일반화되지 않는다 → 대안 순서: ① 등록자 고정 분류기 ② DTW 단독 ③ 숫자 인식 ④ 제스처 분류. 소규모 데이터에서는 DTW가 CNN보다 나을 수 있다.
- 센서가 하나라도 고장나면 재주문에 3~4일(예비 없음).
- 센서 주소 변경 방식(납땜 점퍼 vs 핀 결선)은 수령 후 확인. 센서 게인·포화는 실측으로 확인.
- 가격은 일부 추정. 국내 부품(자석·폼테이프·점퍼선)은 판매처 가격 미확인. 상세는 `docs/DE2_magic_pen_BOM.xlsx`.
